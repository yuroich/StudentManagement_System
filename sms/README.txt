STUDENT MANAGEMENT SYSTEM - SETUP (XAMPP)
1. Copy this whole folder to  C:\xampp\htdocs\student_management
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Open http://localhost/phpmyadmin -> Import -> choose database.sql -> Go.
4. Put your background picture at assets/img/bg.jpg (login/sign-up page).
5. Open http://localhost/student_management/
   Admin login:  username: admin   password: 1234
6. Errors are written to logs/error.log
If your MySQL has a root password, edit config/db.php.
